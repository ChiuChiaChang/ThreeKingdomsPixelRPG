# ThreeKingdomsPixelRPG

Original Three Kingdoms browser Pixel RPG. Version **1.1.0.0** upgrades the prototype into a CSS pixel-art battle presentation without copying third-party game sprites.

## Run
```bash
git clone https://github.com/ChiuChiaChang/ThreeKingdomsPixelRPG.git
cd ThreeKingdomsPixelRPG
npm install
npm start
```
Development: `npm run dev`

## v1.1.0.0
- Original animated CSS pixel warriors
- 5 vs 5 turn-based battle
- Selectable commander
- HP / SP and segmented bars
- Attack, thunder, fire, healing, formation and strategy skills
- Battle VFX, hit/heal animations, enemy AI
- KO, victory and defeat states
- Responsive desktop/mobile battlefield

All character graphics in this repository are generated from CSS primitives and are original placeholder artwork.
