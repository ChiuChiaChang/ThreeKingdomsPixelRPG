# ThreeKingdomsPixelRPG

三國題材原創像素風回合制 RPG prototype。

## Version
1.0.0.0

## Run

```bash
git clone https://github.com/ChiuChiaChang/ThreeKingdomsPixelRPG.git
cd ThreeKingdomsPixelRPG
npm install
npm start
```

開發模式也可使用 `npm run dev`。

## Current features
- 5 vs 5 三國武將戰鬥
- HP / SP
- 攻擊與計策選單
- 敵方自動反擊
- 勝利 / 敗北判定
- Responsive desktop/mobile UI

> Character artwork in future releases should use original or properly licensed assets rather than copied game sprites.
